# ボード上下字幕スペース仕様書

## 概要

ゲームボードの上下にある空白スペースに、ゲーム状況を示す字幕（サブタイトル）を追加する。

## 背景・目的

現在のUI構成では、CPU手持ち駒エリアとボードの間、およびボードとプレイヤー手持ち駒エリアの間に空白スペースが存在する。このスペースを有効活用し、各プレイヤーの状態や補足情報を表示することで、ゲーム体験を向上させる。

## 現状分析

### 現在のレイアウト構造

```
┌─────────────────────────────┐
│  ヘッダー (GOBBLET ★★)     │
├─────────────────────────────┤
│  CPU手持ち駒エリア          │
├─────────────────────────────┤
│  【空白スペース①】 ← 字幕追加対象  │
├─────────────────────────────┤
│                             │
│     ゲームボード (4×4)      │
│                             │
├─────────────────────────────┤
│  【空白スペース②】 ← 字幕追加対象  │
├─────────────────────────────┤
│  YOU手持ち駒エリア          │
├─────────────────────────────┤
│  メッセージバー             │
│  ボタン群                   │
└─────────────────────────────┘
```

### 現在のスペーシング

- 親コンテナの `gap: 6px` で要素間隔を管理
- ボードコンテナの `padding: 8px`
- 中央スペーサー `flex: '1'` で可変スペースを確保

## 要件定義

### 機能要件

#### 1. 上部字幕（CPU側）

| 項目 | 内容 |
|------|------|
| 配置位置 | CPU手持ち駒エリアとボードの間 |
| 表示内容 | CPUの思考状態・行動を示すテキスト |
| 表示例 | 「考え中...」「配置しました」「あなたの番です」 |

#### 2. 下部字幕（プレイヤー側）

| 項目 | 内容 |
|------|------|
| 配置位置 | ボードとYOU手持ち駒エリアの間 |
| 表示内容 | プレイヤーへのガイド・ヒントテキスト |
| 表示例 | 「駒を選択してください」「配置先を選択」「勝利！」 |

### 表示パターン

#### 上部字幕（CPU状態表示）

| ゲーム状態 | 表示テキスト |
|-----------|-------------|
| プレイヤーのターン | （非表示または空白） |
| CPUの思考中 | 「🤔 考え中...」 |
| CPU配置完了 | 「📍 配置しました」 |
| CPU勝利 | 「🏆 CPUの勝ち！」 |
| CPU敗北 | 「😢 負けました...」 |

#### 下部字幕（プレイヤーガイド）

| ゲーム状態 | 表示テキスト |
|-----------|-------------|
| 駒選択待ち | 「👆 駒を選択してください」 |
| 配置先選択待ち | 「📍 配置先を選択してください」 |
| CPUのターン | 「⏳ CPUのターンです」 |
| プレイヤー勝利 | 「🎉 勝利！おめでとう！」 |
| プレイヤー敗北 | 「😔 残念...もう一度！」 |
| 引き分け | 「🤝 引き分け」 |

## UIデザイン仕様

### 字幕コンポーネント共通スタイル

```
位置: 各スペース内で水平中央揃え
高さ: 20px〜24px（テキスト含む）
最小高さ: 16px（スペース確保）
```

### タイポグラフィ

| 属性 | 値 |
|------|-----|
| フォントファミリー | 'Cinzel', serif（既存と統一） |
| フォントサイズ | 12px〜14px |
| フォントウェイト | 500 |
| 行高 | 1.4 |
| 文字間隔 | 0.5px |

### カラー

| 要素 | カラーコード | 説明 |
|------|-------------|------|
| 通常テキスト | #d4a574 | 既存のゴールドカラー |
| 薄いテキスト | #a89070 | セカンダリテキスト |
| ハイライト（勝利等） | #f1c40f | アクセントイエロー |
| エラー/敗北 | #e74c3c | 警告レッド |

### アニメーション

| 状態変化 | アニメーション |
|---------|---------------|
| テキスト切り替え | フェードイン（0.3s ease） |
| 思考中 | パルス点滅（1.5s infinite） |
| 勝敗表示 | スケールイン（0.4s ease-out） |

## コンポーネント設計

### 新規コンポーネント: `SubtitleBar`

```
Props:
  - text: string          // 表示テキスト
  - position: 'top' | 'bottom'  // 配置位置
  - variant: 'normal' | 'highlight' | 'warning' | 'thinking'  // スタイルバリアント
  - visible: boolean      // 表示/非表示
```

### 状態管理

既存の状態を活用：
- `turn`: 現在のターン（'player' | 'cpu'）
- `selectedPiece`: 選択中の駒
- `winner`: 勝者
- `isThinking`: CPU思考中フラグ（新規追加の可能性）

## 技術的考慮事項

### パフォーマンス

- 字幕更新は状態変化時のみ
- アニメーションはCSS transitionで実装（React再レンダリング最小化）

### アクセシビリティ

- 字幕テキストは `aria-live="polite"` で読み上げ対応
- 十分なコントラスト比を確保（WCAG AA準拠）

### 既存機能への影響

- メッセージバー（下部）との役割分担を明確化
  - 字幕: リアルタイムの状態ガイド
  - メッセージバー: 重要な通知・結果表示

## 実装優先度

1. **Phase 1**: 基本的な字幕表示（静的テキスト）
2. **Phase 2**: ゲーム状態連動（動的テキスト切り替え）
3. **Phase 3**: アニメーション追加
4. **Phase 4**: レスポンシブ調整・微調整
